Hub Bookshop editor

1. Click Open books.json and choose the assets/data/books.json file. 2. Edit, add or remove books. 3. Click Download books.json and replace the file in the website folder. Leave Price empty to show "Ask for price". Cover is optional: type the name of an image file you put in assets/img/books/, for example assets/img/books/my-book.jpg.
